Executive Summary

RepurposeAlpha is a decision support platform for non-commercial drug repurposing. It combines eight analytical features — portfolio optimization, real options valuation, freedom-to-operate screening, adaptive trial design, cross-disease discovery, negative results intelligence, combination synergy, and cost-based pricing — into a single tool built entirely on free, public data.

The global drug repurposing market was valued at approximately $37 billion in 2025 and is projected to reach $41 billion in 2026, growing at 9.6% CAGR.[12] However, existing tools serve the commercial pipeline. Academic labs, rare disease foundations, and neglected tropical disease researchers lack access to the same decision-support capabilities.

This document provides the complete mathematical foundation for each feature, the assumptions behind every input, and a comparison with tools currently available in the market.

1. The Base Pipeline

When a user types a disease name, four operations run in sequence:

1.1 Discovery — Disease to Candidates

Logic: Query Open Targets Platform GraphQL API for all drugs associated with the disease, filtered to max clinical stage ≥ Phase 2.

Data source: Open Targets Platform (free, public). Query uses drugAndClinicalCandidates field on the disease type.

Assumptions: None. This is raw data retrieval.

Output: A DataFrame of candidates with ChEMBL IDs, drug names, and clinical stage.

1.2 Correlation — Drug-Drug Similarity

Logic: For each pair of drugs, compute a composite similarity score from seven independent biological signals.

correlation(i,j) = Σ (weight_s × similarity_s(i,j)) for s in signals Where signals = {target overlap, affinity similarity, chemical structure, Murcko scaffold match, mechanism of action, ATC code hierarchy, assay description similarity} Weights are selected by entropy weighting: signals with higher information content (lower entropy, higher variance) receive higher weight.

Data sources: ChEMBL bioactivity data, RDKit molecular fingerprints, WHO ATC classifications.

AssumptionValueSource
Binding affinity threshold≤ 1 μMStandard pharmacology practice
Tanimoto fingerprint radius2, 2048 bitsRDKit default
Entropy weightingInverse Shannon entropy with variance floorInformation theory
Species blocklist~20 whole-organism entriesManual curation
Validated: 11× signal-to-noise ratio on known drug families (artemisinins: 0.32 within-family vs 0.03 between-family).

1.3 Returns — Expected Return Estimator

Logic: Estimate each candidate's risk-adjusted return using a phase-based rNPV proxy.

mu(i) = PoS(phase) × revenue_proxy(phase) − (1 − PoS(phase)) × cost_proxy(phase) sigma(i) = volatility_base(phase) + novelty_adjustment Where: PoS = probability of success by phase (BIO/QLS 2021) revenue_proxy = estimated revenue relative to Phase 3 cost cost_proxy = cumulative cost to reach approval from this phase novelty_adj = ±0.05 based on peer count in candidate set

Final mu is normalized to [0.05, 0.20] annual return range for realistic Sharpe ratios.

PoS Phase 358%BIO/QLS
PoS NDA/BLA85%BIO/QLS

Honest limit: Returns are phase-based, not drug-specific. Two Phase 3 drugs get identical expected returns.

1.4 Optimization — Markowitz Portfolio

Logic: Maximize the Sharpe ratio subject to long-only constraints.

Maximize: (μ_p − r_f) / σ_p Where: μ_p = Σ wᵢ × μᵢ (portfolio return) σ_p = √(Σᵢ Σⱼ wᵢ × wⱼ × σᵢ × σⱼ × ρᵢⱼ) (portfolio volatility) r_f = risk-free rate (FRED DGS10, live) wᵢ ≥ 0, Σ wᵢ = 1 (long-only, fully invested)

Solved using: PyPortfolioOpt (Ledoit-Wolf covariance, max Sharpe).

Market context: Modern portfolio theory has been applied to pharma R&D since at least 2016.[14] BridgeBio was founded explicitly on Markowitz principles.[14] However, commercial platforms like Intelligencia Portfolio Optimizer and Captario SUM focus on large pharma portfolios and are priced for enterprise.[1][2] No open-source tool applies Markowitz to repurposing candidate selection for non-commercial users.

2. Feature Breakdown

2.1 Real Options Valuation

"When should I kill it?"

Logic: Model drug development as a binomial lattice with embedded abandonment options at each phase gate.

Cox-Ross-Rubinstein parameters: u = e^(σ√Δt) (up factor) d = 1/u (down factor) p = (e^(rΔt) − d) / (u − d) (risk-neutral probability) Backward induction: V(node) = max(e^(−rΔt) × [p × V_up + (1−p) × V_down] − cost, 0) Gate decision: continue if sub-tree value > 0, abandon otherwise.
AssumptionValueSource
Volatility40%Industry benchmark
Profit margin30%Industry average
Time steps10Standard for lattice resolution
Phase costs$1M–$100MDiMasi 2016, Wouters 2020
Honest limit: Uses industry-average phase costs and success rates. Real numbers vary by disease and drug class.
Market context: Real options analysis is well-established in academic literature for pharmaceutical R&D.[4] WIPO recognises the method for valuing biotechnology assets.[4] However, no existing tool implements it specifically for repurposing candidate kill decisions. The method exists in theory; RepurposeAlpha implements it in practice.

2.2 Freedom-to-Operate Screening

"Can I sell it?"

Logic: Rule-based scoring system using curated drug classification lists.

score = f(stage, is_generic, is_biologic) if generic: score = 0.15 (high risk) elif biologic: score = 0.55–0.75 (low risk) elif approved: score = 0.40 (medium risk) elif phase_3: score = 0.65 (low risk) elif phase_2: score = 0.75 (low risk) Risk buckets: ≥0.60 = low, 0.40–0.60 = medium, <0.40 = high
AssumptionSourceConfidence
Generic drug list (~30 entries)Manual curationLow
Biologic drug list (~10 entries)Manual curationLow
Stage-to-score mappingHeuristicLow
Honest limit: This is the weakest feature. Real FTO requires FDA Orange Book, USPTO PatentsView, and actual orphan designation records — all either paywalled or complex to integrate. This is a screening signal, not legal advice.
Market context: Commercial FTO tools (DrugPatentWatch, PatSnap, CAS SciFinder) cost thousands per year and are designed for legal/IP teams.[5] RepurposeAlpha provides a first-pass screen at zero cost. It is not a replacement for professional FTO analysis.

2.3 Adaptive Trial Design Recommender

"How should I test it?"

Logic: Compare three trial architectures by expected sample size, duration, and cost.

Fixed sample size (2-arm, continuous endpoint): n_per_arm = 2 × ((z_α/2 + z_β) / effect_size)² For N candidates: n_fixed = n_per_arm × N n_adaptive = n_fixed × efficiency_ratio(N) n_platform = n_fixed × (1/√N) Cost = n_total × cost_per_patient ($25,000)
AssumptionValueSource
Effect size0.25 (moderate)Standard assumption
Alpha / Power0.05 / 0.80FDA convention
Cost per patient$25,000Industry average
Adaptive efficiency ratios0.60–0.85Empirical literature
Market context: Open-source packages like rpact, BATSS, and TrialSimulator provide sophisticated adaptive design simulation.[6] Commercial tools like Cytel East are the industry standard.[6] However, none of these tools combine trial design with portfolio-level candidate selection. RepurposeAlpha's unique contribution is the comparison across architectures for a portfolio of candidates, not a single trial.

2.4 Cross-Disease Mechanism Discovery

"What else does it treat?"

Logic: Query Open Targets for all diseases associated with each drug.

For each candidate: other_diseases = OpenTargets.drug(chembl_id).indications n_other = count(other_diseases excluding current disease)

No mathematical assumptions. This is raw database retrieval.

AssumptionSource
Disease coverageOpen Targets annotation quality varies by disease area
No inferenceWe report what Open Targets records — nothing more
Market context: Open Targets itself provides this data through its web interface.[3] RepurposeAlpha's contribution is integrating it into a portfolio-level view: a scientist sees not just "this drug is used in 15 diseases" but "here's how that relates to my candidate set."

2.5 Negative Results Intelligence

"Has it already failed?"

Logic: Weighted scoring of terminated trials by failure type and recency.

weighted_risk = Σ (failure_strength × decay) Where: failure_strength = {FUTILITY: 1.0, SAFETY: 1.0, ENROLLMENT: 0.3, BUSINESS: 0.2, UNKNOWN: 0.5} decay = 0.5 ^ (years_ago / 5) (5-year half-life) Risk buckets: ≥2.0 = high, 1.0–2.0 = medium, 0.3–1.0 = low, <0.3 = clean
AssumptionValueSource
Failure type weights0.2–1.0Heuristic (see rationale below)
Half-life5 yearsJudgment — scientific context changes
Risk thresholds0.3 / 1.0 / 2.0Heuristic

Why the weights: Futility and safety failures are strong negative signals (the science failed). Enrollment and business failures are weak signals (logistics failed, not biology). This distinction is documented in the literature: "Clinical trials can fail for numerous reasons unrelated to drug efficacy or toxicity, such as poor participant enrollment, lack of funding."[7]

Market context: RepoDB is the standard dataset for repurposing success/failure benchmarking.[7] However, it aggregates failures without distinguishing type. ClinicalTrials.gov holds the raw data, but no tool surfaces it specifically for repurposing candidate screening. RepurposeAlpha's contribution is the failure-type weighting — a drug that failed for enrollment is not the same as one that failed for futility.

2.6 Combination Synergy Predictor

"What pairs well with it?"

Logic: Score every pair by mechanism complementarity (correlation-based) plus prior combination trial evidence.

complementarity(corr): if corr < 0.05: return 0.30 + corr × 4.0 (unrelated) if 0.05 ≤ corr ≤ 0.50: return 0.80 (sweet spot) if 0.50 < corr ≤ 0.80: return 0.80 − (corr−0.50) × 2.0 if corr > 0.80: return 0.20 (redundant) synergy = 0.7 × complementarity + 0.3 × (1 if prior_trial else 0)
AssumptionValueSource
Correlation sweet spot0.1–0.5Judgment (shared context, different mechanism)
Complementarity weight0.7Judgment
Prior trial weight0.3Judgment

Independent validation: The tool independently identified Sulfadiazine + Trimethoprim as a top pair. Those two are sold together as co-trimoxazole — a real, marketed combination. That's one validation point, not a full validation.

Market context: Sophisticated synergy prediction tools exist (SynergyFinder, DeepSynBa, PanThera).[11] These use dose-response matrices and deep learning on cell-line data. They are more accurate but require experimental data. RepurposeAlpha's heuristic works with zero experimental input — a significant limitation and a significant advantage for early-stage screening where no synergy data exists.

2.7 Cost-Based Pricing Framework

"What price works?"

Logic: Estimate the minimum sustainable price per patient per year to recover development costs.

required_revenue = dev_cost × (1 + WACC × years) sustainable_price = required_revenue / (target_patients × years) Where: dev_cost = cumulative phase costs from registry WACC = 10% (cost of capital) years = 7 (recovery period) target_patients = prevalence × market_share (15%) Market reference by disease category: rare_disease: $150K | NTD: $500 | common: $5K | oncology: $120K
AssumptionValueSource
WACC10%Industry standard
Recovery years7Judgment
Market share15%Conservative estimate
Reference pricesCategory averagesPublic pricing databases
Honest limit: Market share is a guess. Prevalence estimates vary. Real pricing is negotiated, not formulaic.
Market context: Commercial pricing tools exist for market access and reimbursement strategy. However, none are designed for early-stage repurposing decision-making. RepurposeAlpha's contribution is answering "can this price even work?" before the project starts — a question no existing tool answers.

4. Honest Limitations

What RepurposeAlpha Is

A decision support tool for non-commercial drug repurposing. It combines eight features that no other single tool provides, built entirely on free public data.

What RepurposeAlpha Is Not:
• Not a replacement for professional FTO analysis (consult a patent attorney)
• Not a predictor of clinical success (RepoDB's structure makes supervised ML infeasible — documented)
• Not a substitute for wet-lab validation (it prioritizes, not proves)
• Not an enterprise SaaS (single-tenant is the current model)
