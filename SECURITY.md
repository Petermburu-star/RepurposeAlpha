# Security Policy — RepurposeAlpha

## Commitments
1. Encryption in transit and at rest (TLS 1.2+ / AES-256).
2. Role-Based Access Control (RBAC).
3. Two-Factor Authentication (2FA).
4. API key signatures on every endpoint.
5. Comprehensive audit logging.
6. HIPAA / GDPR alignment from Day 1.
7. No secrets in code — env vars only.
